ИСПРАВЛЕНИЕ ETHEREUM MAINNET — 07.11.2026
========================================

Исходный balances_all.csv пользователя: 91 кошелёк, 7553 проверок,
355 ошибок, все в сети ethereum.
В частности: DAI 91, WBTC 91, USDC 79, WETH 44, LINK 42, USDT 5, ETH 3.
Причина: скрипт ошибочно считал общие ошибки RPC -32603 Internal error
и -32000 eth_call not supported окончательными, не переключаясь
на другие RPC. Сбой decimals() распространялся сразу на все адреса токена.

ЧТО ИЗМЕНИЛОСЬ
- При -32603 и ошибках провайдера проверяет другие RPC.
- Если конкретный RPC не поддерживает eth_call, убирает его только из
  выбора для eth_call; для eth_getBalance этот RPC по-прежнему доступен.
- --probe-only проверяет не только chainId и блок, но и eth_call / decimals().
- Новый --retry-errors читает reports/balances_all.csv и повторяет только
  строки ERROR. Успешные балансы других кошельков/сетей не перечитывает.
- При наличии предыдущего --usd автоматически пытается оценить новые
  успешные позиции; --usd можно передать явно.
- Перед перезаписью reports/balances_all.csv создаёт копию
  reports/balances_all.before_retry_*.csv.
- Новые пользовательские RPC в extra_rpcs.json теперь идут в начале,
  а не отбрасываются при лимите пяти RPC на сеть.

УСТАНОВКА В СУЩЕСТВУЮЩИЙ ПРОЕКТ
1. Сохраните старый checker.py на всякий случай.
2. Замените checker.py на одноимённый файл из этого архива.
3. НЕ ЗАМЕНЯЙТЕ addresses.txt, tokens.json, networks.json, каталог reports/.
4. Файл report_view.py из прошлого обновления должен оставаться рядом
   с checker.py (новый архив его не изменяет).

КОМАНДЫ НА MAC ИЗ ПАПКИ ПРОЕКТА (с активным .venv)

  python checker.py --probe-only --only ethereum

Проверьте reports/rpc_probes.json: важно, чтобы для Ethereum хотя бы
один RPC имел "eth_call": "ok".

  python checker.py --retry-errors --only ethereum --usd

После завершения:

  open reports/portfolio.html

Оставшиеся ошибки — в reports/errors.csv, сведения о RPC — в
reports/rpc_health.json. Повторная команда --retry-errors работает только
по оставшимся ERROR-строкам. При полном успехе число ошибок снизится
с 355 до 0, а итоговый USD будет пересчитан. Это НЕ гарантируется:
публичные RPC могут быть недоступны, ограничены по частоте запросов
или не поддерживать нужные методы.

Если RPC перегружены, попробуйте:
  python checker.py --retry-errors --only ethereum --usd --timeout 15 --network-concurrency 1 --address-concurrency 1

Если все бесплатные RPC не работают, добавьте свой надёжный
HTTPS-RPC в extra_rpcs.json по образцу extra_rpcs.example.json.
Не публикуйте приватные API-ключи и никогда не передавайте seed-фразы.

ВАЖНО: Скрипт только читает балансы известных ERC-20 контрактов.
Он не переводит монеты, не ищет все токены на адресе и не позволяет
обещать абсолютную полноту портфеля без индексатора токенов.
